# 币安广场抽奖工具

这个本地工具的逻辑是：打开目标帖子，读取币安广场帖子详情里的 `quoteCount`，再直接分页请求帖子引用列表和评论列表接口，筛出已一键三连用户。

它不会破解平台、不会读取隐藏数据库、不会把数据上传到外部服务。它只会打开一个你能看到的浏览器窗口，读取币安网页正常请求到本机浏览器里的公开/已登录可见响应。

## 能做什么

- 打开币安广场目标帖子。
- 自动读取帖子详情，拿到引用数量和作者 UID。
- 直接分页读取 `queryQuoteContents` 引用列表 JSON。
- 先读取引用名单，再读取评论列表时只匹配引用用户。
- 找到全部引用用户的评论记录后会提前停止。
- 从匹配结果里生成“已一键三连用户”名单。
- 从最终名单里抽奖。
- 导出用户主页链接、引用帖链接、评论证据、CSV 和 JSON。

## 不能做什么

- 帖子页面的引用数量是“引用帖数量”，工具默认按用户去重；同一用户引用多次时，唯一用户数会少于页面数字。
- 如果币安接口不返回某些已删除、隐藏或受限制的引用帖，工具无法凭空恢复。
- 如果平台需要登录或验证码，需要你在打开的浏览器里手动完成。

## 使用

```powershell
cd C:\Users\admin\Documents\project\binance-square-repost-finder
npm install
npm run start
```

然后打开：

```text
http://127.0.0.1:8787
```

## 操作建议

1. 填目标帖子链接。
2. 先点“1 打开帖子窗口”。
3. 在弹出的币安窗口里登录账号或完成地区确认，并确认能看到目标帖子。
4. 回到工具页，默认“最多接口页”是 500。
5. 点“2 读取数据”。
6. 等记录结束，在本地页面看已一键三连用户名单、抽奖并导出。

记录结束后，币安窗口会继续保留，方便你换帖子后重复记录。

## 命令行模式

```powershell
npm run scan -- --target https://www.binance.com/zh-CN/square/post/... --maxSeconds 1200 --maxPages 500
```

## 隐私说明

- 浏览器资料保存在本项目的 `.runtime/chrome-profile`。
- 每次记录结果保存在 `.runtime/runs`。
- 默认不保存完整网络响应正文，只保存候选用户、主页链接、引用帖链接、接口路径和状态码。
- 如果你不想保留登录态，关闭工具后删除 `.runtime/chrome-profile` 即可。
